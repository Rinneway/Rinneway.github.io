# 🎮 Web Platformer

Небольшой веб-платформер, созданный в подарок девушке. ❤️

Проект написан на **HTML**, **CSS** и **JavaScript** и опубликован с помощью **GitHub Pages**. Игра работает на любых устройствах.

---

## 🚀 Запуск

Игра доступна через **GitHub Pages** (ссылка в самом верху файла README).
---

## 🎮 Управление

- **A** / **←** — движение влево
- **D** / **→** — движение вправо
- **W** / **Space** / **↑** — прыжок

---

## 🕹️ Как пройти игру

Чтобы завершить уровень, необходимо:

- ❤️ собрать **все сердца**, расположенные на уровне;
- 🚪 найти проход на следующий уровень.

После прохождения каждого уровня игрок получает **часть секретного кода**.

Когда все уровни будут пройдены, соберите все части кода и введите его в замок — так вы сможете открыть **финальное послание**, подготовленное специально для получателя игры. 💖

---

## 👾 Враги

На уровнях встречаются различные противники.

- 🦶 Большинство врагов побеждаются **тремя прыжками им на голову**.
- 👑 Однако существует **один секретный враг**, которого нельзя победить таким способом.
